# Community Learning Center Management System

## Project Description
A console-based Dart application designed to manage learning resources and participants in a Community Learning Center.

## Features
- Add learning resources
- Register participants
- Borrow learning resources
- Return learning resources
- View all records
- Generate a center report
- Validate user input

## Technologies Used
- Dart Programming Language
- Object-Oriented Programming
- OnlineGDB
- GitHub

## Sample Test Scenarios
1. Add a learning resource successfully.
2. Register a new participant.
3. Borrow an available resource.
4. Attempt to borrow an already borrowed resource.
5. Return a borrowed resource.
6. Enter invalid menu input.

## How to Run
1. Open https://www.onlinegdb.com/online_dart_compiler
2. Copy the contents of `main.dart`.
3. Paste the code into the editor.
4. Click Run.
